# Supplemental files
- individual_input_data: JSON-formatted individual experimental data, including 26 male and 26 female mice
- individual_network: image files of individual-specific network obtained from BVN inference
- python_codes: full codes for inferring using depression and brain BVN model
  * Please see the [original BVN repository](https://github.com/fumikawano-lab/Bioreaction-Variation-Network) for the pipeline of pre-training and for downloading the pre-trained model.


- All community data.xlsx: showing the full data of community components and their centralities
- Primer sequences.xlsx: showing the primer sequences for gene expression analysis
- Supplemental Table S1: individual data in Euclidean distance between the input features and predicted features in BVN inference
- Supplemental Figure S1: training loss progression during pre-training of depression and brain BVN model
